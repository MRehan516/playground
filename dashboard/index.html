What LegacyFlow Does
🔍
Field Impact Analysis
Traces a target field across every RPG, CLLE, and copybook file in your codebase. Produces a complete reference map with read sites, write sites, and conditional branches — in minutes, not weeks.
📋
Business Rules Extraction
Surfaces implicit business logic buried in decades-old RPG source — validation rules, state transitions, threshold values, and duplicate rule patterns — presented as a structured, reviewable catalogue.
⚖️
Risk Scoring
Quantifies change risk on a 1–10 scale using seven evidence-based factors: file spread, branching logic complexity, batch job involvement, shared copybook usage, and more.
⏱
Effort Estimation
Compares estimated manual analysis hours against LegacyFlow-assisted hours, breaking down effort per file with reference-count breakdowns for constants, writes, reads, and conditional logic.
