About LegacyFlow Orchestrator

A proof-of-concept IBM Bob 2.0 application demonstrating AI-driven intelligence for IBM i / RPG modernization teams.

What It Solves
The Problem
IBM i modernization projects routinely stall during the initial discovery phase. Before any code can be safely changed, teams must manually trace field usage across hundreds of RPG, CLLE, and copybook files — a task that takes experienced developers weeks to complete and is highly error-prone. Business rules buried in inline conditionals are routinely missed, leading to defects introduced during modernization.
The Solution
LegacyFlow automates discovery entirely. By deploying IBM Bob 2.0 as an orchestration engine with two parallel analysis skills, the same work that took weeks now completes in minutes — producing structured, reviewable outputs that a team can act on immediately. The risk score and effort estimate give managers the data they need to prioritise and resource the modernization work correctly.
Key Capabilities
Impact Analysis Skill
Traces a named field across all source files. Identifies every read site, write site, conditional branch, constant definition, and copybook inclusion. Produces a call chain diagram and a complete reference breakdown per file.
Business Rules Extraction Skill
Reads source code semantically to catalogue validation rules, state transition logic, threshold constants, and guard clauses. Detects duplicate rule implementations across files and flags them for consolidation.
Risk Scoring Engine
Computes a 1–10 risk score using seven evidence-based factors. Each factor is scored individually, deductions are applied for mitigating factors (e.g. centralised validation), and a human-readable rationale is produced alongside the number.
Effort Estimation
Produces side-by-side estimates: manual analysis hours vs. LegacyFlow-assisted hours, with a per-file reference count breakdown so teams can identify which files will require the most attention.

Limitations & Scope
LegacyFlow is a proof of concept built for hackathon demonstration. The analysis quality depends on the quality of the Bob skill instructions and the LLM's ability to read RPG source code semantically. It is not a static analysis tool and does not parse source code with a grammar — it uses AI reasoning, which means results should be treated as AI-assisted intelligence requiring human review, not as ground-truth automated output.
