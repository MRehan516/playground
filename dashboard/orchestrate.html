Why --yolo?
Bob's Plan mode normally pauses for human approval before executing. The --yolo flag bypasses the approval gate, enabling fully automated runs. This is safe here because the INSTRUCTIONS.md is authored so Bob's plan is deterministic and all codebase access is read-only — the only writes are to the project output directory.
What Bob produces
Each run produces 6 structured files: impact-report.md, business-rules.md, risk-score.json, effort-estimate.json, plan.md, audit-trail.md. All are immediately viewable in the Results Viewer dashboard.
